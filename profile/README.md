<h2 align="center">Cockpit</h2>

<p align="center"><b>Run ten Claude Code sessions. Read none of them.</b><br>
A free, open-source desktop app that turns Claude Code's terminal text into cards you answer with one key.</p>

<p align="center"><a href="https://getcockpit.github.io/#film"><img src="https://getcockpit.github.io/assets/hero.gif" width="720" alt="Cockpit in action"></a></p>

- **One queue** for every question, permission and plan across all your sessions
- **Risk in red** before a command runs, with exactly what it will do
- **Plans as a map**, a timeline of who needs you next, and guided PR review
- **Your own Claude plan**, no server, no account; macOS, Windows and Linux

```bash
curl -fsSL https://getcockpit.github.io/install.sh | bash
```
