<h2 align="center">Cockpit</h2>

<p align="center"><b>Run more Claude Code sessions without losing track.</b><br>
Cockpit runs your sessions side by side and pulls everything that needs you into one queue, with the exact command or question in front of you. One key each, and every session keeps moving.</p>

<p align="center"><a href="https://getcockpit.github.io/#film"><img src="https://getcockpit.github.io/assets/hero.gif" width="720" alt="Cockpit in action: eight sessions, one queue, one key"></a></p>

A desktop app for the Claude Code you already have. Your terminal and tmux keep working.

- **One queue** for every question, permission and plan across all your sessions, answered with one key
- **Keep your terminal:** prompts from Claude Code in tmux, iTerm or a plain terminal land in the same queue
- **Risk in red** before a command runs, with exactly what it will do
- **Ten sessions, zero collisions:** each works in its own copy of your repo
- **Plans you can read**, a timeline of who needs you next, guided PR review and a PR report
- **Your own Claude plan**, no server, no account; macOS, Windows and Linux

```bash
# macOS or Linux
curl -fsSL https://getcockpit.github.io/install.sh | bash
```

```powershell
# Windows (PowerShell)
irm https://getcockpit.github.io/install.ps1 | iex
```
